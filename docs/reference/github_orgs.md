# Collect details on the authenticated user's GitHub organization memberships (based on the current PAT).

Collect details on the authenticated user's GitHub organization
memberships (based on the current PAT).

## Usage

``` r
github_orgs(quiet = FALSE)
```

## Arguments

- quiet:

  Logical. Should status messages be shown. Default `FALSE`.

## Value

Returns a tibble with organization details.

## Examples

``` r
if (FALSE) { # \dontrun{
github_orgs()
} # }
```
