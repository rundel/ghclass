# Returns the login of the authenticated user (based on the current PAT).

Returns the login of the authenticated user (based on the current PAT).

## Usage

``` r
github_whoami(quiet = FALSE)
```

## Arguments

- quiet:

  Logical. Should status messages be shown. Default `FALSE`.

## Value

Character value containing user login.

## Examples

``` r
if (FALSE) { # \dontrun{
github_whoami()
} # }
```
